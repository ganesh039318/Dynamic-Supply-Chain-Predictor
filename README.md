# Dynamic Supply Chain & Inventory Predictor

A machine learning project focused on demand forecasting and inventory risk analysis.

## Project Objectives
- Analyze historical retail demand.
- Explore trends and seasonality.
- Build demand forecasting models.
- Identify potential stockout and excess-inventory risks.

## Dataset
Retail Store Inventory and Demand Forecasting dataset.

Dataset source: https://www.kaggle.com/datasets/atomicd/retail-store-inventory-and-demand-forecasting

The dataset CSV is excluded from this repository. Download it separately and place it at data/sales_data.csv.
